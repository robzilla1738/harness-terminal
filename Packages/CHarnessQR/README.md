# QR encoding

Unmodified C encoder and header from Project Nayuki's QR Code generator,
commit `3c6d0b3cefb4e049dc337e82237c9644399716a8`:
https://github.com/nayuki/QR-Code-generator/tree/3c6d0b3cefb4e049dc337e82237c9644399716a8/c

Both files contain the MIT copyright and license. Used by the CLI to print
portable QR codes on macOS and Linux without an external executable. GUI QR
images use Core Image. No cryptographic or authentication logic lives here.
